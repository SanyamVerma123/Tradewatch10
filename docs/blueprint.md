# **App Name**: StockWatch

## Core Features:

- Stock Data Fetch: Fetch real-time stock data for a user-defined watchlist.
- Stock Search and Add: Allow users to search for and add stocks to their watchlist.
- Watchlist Management: Enable users to create and manage multiple watchlists.
- Price Alert Suggestions: Suggest price alerts using a tool. The LLM should observe price movements of stocks on the watchlist and provide price level suggestions.
- Performance Tracking: Track and display the performance of stocks in the watchlist (gain/loss, percentage change).
- News Aggregation: Fetch the latest news articles related to stocks on the user's watchlist from a news API.
- UI Navigation: Bottom navigation bar for Watchlist, Orders, Portfolio, Apps and Profile views.

## Style Guidelines:

- Background color: Light grey (#F5F5F5) to provide a clean and neutral base.
- Primary color: Soft blue (#64B5F6) for interactive elements like the watchlist indicator and stock prices.
- Accent color: Light green (#A5D6A7) to indicate positive stock performance; red (#E57373) for negative performance.
- Font: 'Inter', a sans-serif font, for a modern, clean interface. Used for both headlines and body text.
- Use simple, line-based icons for the bottom navigation bar.
- Tabbed layout for watchlists at the top, followed by a search bar and the list of stocks.
- Subtle animations when updating stock prices or switching between watchlists.
